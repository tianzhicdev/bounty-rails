Method. We search GitHub for open bounty issues (label:bounty, USDC/USD/bounty in title, state:open), fetch each issue body + recent comments via the public API, then classify the payout rail — the actual mechanism by which a winner gets paid. That, not the headline amount, decides whether a bounty is worth a minute of your time. Tooling: ghscan.py → railcheck.py in a public monorepo; this page is regenerated from the vetted data.
